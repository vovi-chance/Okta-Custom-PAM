Flow Summary

  1. 1Entry: User hits Cloud Run via HTTPS → Express middleware pipeline processes the request through 7 layers
  2. 2Routing: Unprotected routes (/health, /, /logout, 404) resolve immediately without auth
  3. 3Auth Guards: Protected routes pass through rate limiting → OIDC check → session check → group membership
  4. 4Okta OIDC: If no session, redirect to Okta for Auth Code Flow, then return via callback
  5. 5Page Renders: Authorized GET requests render dashboard.ejs or profile.ejs
  6. 6JIT Request: POST /api/jit-request validates input, builds payload, enters workflow service
  7. 7Workflow Service: Circuit breaker → OAuth 2.0 token (cached or fresh RS256 JWT) → Okta Workflows API with retry
  8. 8Responses: Success (200), validation error (400), forbidden (403), bad gateway (502), or circuit open (503)
